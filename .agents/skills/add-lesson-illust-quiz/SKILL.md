# Add Lesson with Illustrations & Quiz Skill (`add-lesson-illust-quiz`)

This skill extends `add-lesson` by creating a pair of lessons (a Vocabulary Lesson + an Associated Vocab Quiz Lesson), generating clean flat vector SVG illustrations for all vocabulary items, and registering them across the application.

---

## 📌 Workflow Steps

### 1. Ingest Raw Lesson Input & Create Lesson Pair
Given raw input (e.g., `Title: Hobbies (취미)`, words list):
1. **Sanitize & Format Main Vocab Lesson**:
   - ID: `les-<slug>-1` (e.g., `les-hobbies-1`)
   - Type: `vocab`
   - Title: Korean & English title (e.g., `Hobbies (취미)`)
   - Description: Short summary of the vocabulary topic.
   - `paired_quiz_id`: `les-<slug>-quiz-1`
2. **Sanitize & Format Associated Quiz Lesson**:
   - ID: `les-<slug>-quiz-1` (e.g., `les-hobbies-quiz-1`)
   - Type: `vocab quiz`
   - Title: Quiz title (e.g., `Hobbies Quiz (취미 퀴즈)`)
   - Description: Test your knowledge on the vocabulary.
   - `paired_vocab_id`: `les-<slug>-1`
   - `words`: `[]` (dynamically generated by `quizGenerator.js` from paired vocab).

### 2. Format & Sanitize Words Array (Rules #7 & #10 Compliance)
For each word in the list:
- **Clean Korean**: Fix spacing typos (e.g. `물어 보세요` $\rightarrow$ `물어보세요`).
- **Resyllabified Romanization (Rule #10)**: Carry final consonants (받침) to following vowel syllables (e.g. `들으세요` $\rightarrow$ `deu-reu-se-yo`, `읽으세요` $\rightarrow$ `il-geu-se-yo`, `수영` $\rightarrow$ `su-yeong`, `독서` $\rightarrow$ `dok-seo`).
- **Lowercase English (Rule #7)**: Format translations in **all lowercase** (e.g., `cooking`, `baseball`, `reading`), unless a proper noun (`Korea`).
- **Item IDs & Category**: Assign unique item IDs (`hob-1`, `hob-2`, etc.) and relevant category tags (`Hobbies`, `Vocab`).

### 3. Generate Flat Vector SVG Illustrations
For every word item in the lesson:
1. Create a modern, minimalist flat SVG file saved to `public/illustrations/{wordId}.svg` (e.g. `public/illustrations/hob-1.svg`).
2. Design Specifications:
   - `viewBox="0 0 100 100"`
   - Vibrant color palette (`#EF4444`, `#F97316`, `#10B981`, `#3B82F6`, `#8B5CF6`, `#F472B6`).
   - Clean, rounded stroke joins (`stroke-linecap="round" stroke-linejoin="round"`).
   - Recognizeable geometric representations without text labels or visual noise.
3. **Register in `VocabIllustration.jsx`**:
   - Add all new word IDs (e.g., `'hob-1'`, `'hob-2'`, ...) to the `availableIds` array inside [`src/components/VocabIllustration.jsx`](file:///home/tamy/p/ukc-learning-app/src/components/VocabIllustration.jsx).

### 4. Determine Order Indexes (Live DB Check: End of Pathway)
1. **Query Live Supabase DB**: Query table `public.lessons` for all existing `order_index` values.
2. **Calculate Next Order Indexes**:
   - Find maximum `order_index` currently in DB (`maxOrder`).
   - Set main vocab lesson `order_index = maxOrder + 1`.
   - Set associated quiz lesson `order_index = maxOrder + 2`.

### 5. Database & Workspace Synchronization
1. **Live Supabase Upsert**: Upsert BOTH lesson records to table `public.lessons` using [add_lesson_to_db.js](file:///home/tamy/p/ukc-learning-app/.agents/skills/add-lesson/scripts/add_lesson_to_db.js).
2. **User Access Sync**: Append BOTH lesson IDs to `assigned_lesson_ids` for all student users in Supabase DB and [`src/services/userSessionStore.js`](file:///home/tamy/p/ukc-learning-app/src/services/userSessionStore.js).
3. **Schema Seed File**: Append SQL `INSERT` statements for both lessons to [`supabase/schema.sql`](file:///home/tamy/p/ukc-learning-app/supabase/schema.sql).
4. **Reference Documentation**: Append JSON entries for both lessons to [`docs/default_lessons_reference.md`](file:///home/tamy/p/ukc-learning-app/docs/default_lessons_reference.md).

### 6. Verification
- Run `npx vitest run` to ensure quiz generator, pathway rendering, and illustration resolution work without errors.
