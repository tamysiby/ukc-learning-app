## 1. Overview & Learning Objectives

### 1.1 Summary
Hangul (한글) is the phonetic Korean alphabet created in 1443 by King Sejong the Great. Unlike English, Hangul characters are not written in a linear row of single letters; instead, consonants and vowels are assembled into 2D **syllable blocks**.

### 1.2 Learning Objectives
By the end of this lesson, students will be able to:
- [ ] Recognize the core 14 basic consonants and 10 basic vowels.
- [ ] Understand how consonants and vowels combine into syllable blocks `[Initial Consonant + Medial Vowel (+ Final Consonant)]`.
- [ ] Read basic monosyllables and simple words (e.g. `가`, `나`, `다`, `한`, `국`).
- [ ] Identify silent zero-consonant `ㅇ` when placed at the initial position (e.g. `아` = 'ah').

Korean vowels are built from 3 cosmic elements: Sun (`·`), Earth (`ㅡ`), and Human (`ㅣ`).

| **ㅗ** | `o` | 'o' in **o**ver (rounded lips) | `audio_v_o` |

## 3. Part 2: Basic Consonants (자음)

Korean consonants depict the shape of the speech organs (tongue, teeth, lips, throat) during articulation.

| Consonant | Sound / Romanization | Articulation Shape / Guide | Example Syllable |
| :--- | :--- | :--- | :--- |
| **ㄱ** | `g / k` | Tongue blocking back of mouth | `가` (ga) |
| **ㄴ** | `n` | Tongue touching upper gums | `나` (na) |
| **ㄷ** | `d / t` | Tongue tip touching roof of mouth | `다` (da) |
| **ㄹ** | `r / l` | Soft flap 'r' between vowels | `라` (ra) |
| **ㅁ** | `m` | Closed lips forming a box | `마` (ma) |
| **ㅂ** | `b / p` | Closed lips unvoicing | `바` (ba) |
| **ㅅ** | `s` | Teeth shape / s sound | `사` (sa) |
| **ㅇ** | `silent / ng` | Silent at start (`아`), 'ng' at end (`앙`) | `아` (a) |
| **ㅈ** | `j` | Affricate sound | `자` (ja) |
| **ㅊ** | `ch` | Aspirated ch | `차` (cha) |
| **ㅋ** | `k` | Aspirated k | `카` (ka) |
| **ㅌ** | `t` | Aspirated t | `타` (ta) |
| **ㅍ** | `p` | Aspirated p | `파` (pa) |
| **ㅎ** | `h` | Throat shape / h sound | `하` (ha) |

## 4. Part 3: Building Syllable Blocks (글자 조합)

Syllable blocks are assembled in 2 layout styles depending on whether the vowel is **vertical** (ㅣ, ㅏ, ㅑ, ㅓ, ㅕ) or **horizontal** (ㅡ, ㅗ, ㅛ, ㅜ, ㅠ).

### Layout A: Vertical Vowels (Side-by-Side)
$$\text{Consonant (Left)} + \text{Vowel (Right)}$$
- `ㄱ` + `ㅏ` = **가** (*ga*)
- `ㄴ` + `ㅣ` = **니** (*ni*)
- `ㅇ` + `ㅏ` = **아** (*a* - initial `ㅇ` is silent)

### Layout B: Horizontal Vowels (Top-to-Bottom)
$$\text{Consonant (Top)} \over \text{Vowel (Bottom)}$$
- `ㄱ` + `ㅗ` = **고** (*go*)
- `ㄴ` + `ㅜ` = **누** (*nu*)
- `ㅎ` + `ㅡ` = **흐** (*heu*)

### Layout C: Syllables with Final Consonants (받침 - Batchim)
$$\text{Consonant} + \text{Vowel} \over \text{Final Consonant (Bottom)}$$
- `ㅎ` + `ㅏ` + `ㄴ` = **한** (*han*)
- `ㄱ` + `ㅜ` + `ㄱ` = **국** (*guk*)
- Combined word: **한국** (*Han-guk* = Korea)
